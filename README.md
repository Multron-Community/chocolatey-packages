# Multron Chocolatey Packages

Official [Chocolatey](https://community.chocolatey.org) package repository for **Multron Download Manager** and related Multron applications.

## Installation

Install **Multron Download Manager** via Chocolatey:

```powershell
choco install multron-download-manager
```

## Upgrading

```powershell
choco upgrade multron-download-manager
```

## Uninstalling

```powershell
choco uninstall multron-download-manager
```
